class grid_engine.ingestion.PowerHandler[source]

Bases: SimpleHandler

Parses an OSM PBF file to extract power infrastructure data.

Uses PyOsmium’s streaming parser to collect nodes and ways with relevant power tags, storing their attributes in structured dictionaries.

nodes

Dictionaries containing attributes of power nodes.

Type:

list of dict

ways

Dictionaries containing attributes of power ways.

Type:

list of dict

Notes

Must be applied with locations=True to resolve way node coordinates:

>>> handler.apply_file("region.osm.pbf", locations=True)

Examples

>>> handler = PowerHandler()
>>> handler.apply_file("tennessee.osm.pbf", locations=True)
>>> lines = [w for w in handler.ways if w['type'] == 'line']
>>> subs = [w for w in handler.ways if w['type'] == 'substation']
grid_engine.ingestion.nodes_to_geodataframe(nodes)[source]

Converts a list of OSM node dictionaries into a GeoDataFrame.

Parameters:

nodes (list[dict[str, Any]]) – A list of dictionaries representing OSM nodes. Each dictionary must contain 'lon' and 'lat' keys alongside any node attributes.

Returns:

A GeoDataFrame with Point geometries in WGS 84 (EPSG:4326) containing all attributes from the input node dictionaries.

Return type:

geopandas.GeoDataFrame

grid_engine.ingestion.ways_to_geodataframe(ways)[source]

Converts a list of OSM way dictionaries into a GeoDataFrame.

Parameters:

ways (list[dict[str, Any]]) – A list of dictionaries representing OSM ways. Each dictionary must contain a 'coords' key with a sequence of (lon, lat) coordinate tuples alongside any way attributes.

Returns:

A GeoDataFrame with LineString geometries in WGS 84 (EPSG:4326) containing all attributes from the input way dictionaries.

Return type:

geopandas.GeoDataFrame
